# 770 דליים של שמחה – דיווח משפחתי

אתר קטן שבו כל משפחה מדווחת: **איזו משפחה**, **איזו קטגוריה** ו**כמה דליים**.
האתר מציג את ההתקדמות לעבר היעד (770 דליים עד ז' חשון), טבלת משפחות ודיווחים אחרונים.

- `server.js` – שרת Node בלי תלויות. רשימת המשפחות והקטגוריות מוגדרת בראש הקובץ.
- `public/index.html` – האתר עצמו.

## דף מנהל

בכתובת `/admin`, עם סיסמה מהמשתנה `ADMIN_PASSWORD` שמוגדר ב-Railway. אפשר:
- לראות ולסנן את כל הדיווחים ולמחוק דיווח.
- להוסיף, להסיר, לשנות שם ולסדר משפחות. שינוי שם מעדכן גם את הדיווחים הקיימים.
- לערוך קטגוריות: שם, אייקון ושווי ("על כל חצי שעה — 2 דליים").
- לשנות את היעד.

## רישום ליארצייט

כפתור "רישום ליארצייט" בעמוד הראשי פותח טופס: טלפון, שם פרטי, משפחה ושאלות מספריות.
מי שכבר נרשם מקליד את הטלפון והפרטים שלו נטענים לעדכון. כל פעולה נרשמת ביומן.
בדף המנהל, בלשונית "יארצייט": סיכומים, טבלה לפי משפחה, מי עוד לא נרשם, יומן פעולות, הורדה לאקסל,
ועריכה של הכותרת, התאריך, האירועים (שעה ומקום), השאלות, ופתיחה/סגירה של הרישום.
הנתונים נשמרים ב-`yahrzeit.json` וביומן `yahrzeit-log.json` על ה-Volume.

## אחסון

הכול רץ ב-Railway (פרויקט `dliim-simcha`, שירות `dliim-site`).
הדיווחים נשמרים בקובץ `reports.json` וההגדרות בקובץ `config.json`, שניהם על Volume שמחובר לשירות בנתיב `/data`, כך שהם נשמרים גם כשמעלים גרסה חדשה.
בכל יום שבו יש שינוי נשמר עותק בתיקייה `/data/backups` (30 הימים האחרונים). אם קובץ הנתונים נפגם, השרת לא נופל: הוא שומר את הקובץ הפגום בצד (`.corrupt-…`) וממשיך מהגיבוי האחרון.
הורדה של כל הדיווחים לאקסל: `/api/export.csv` (יש קישור בתחתית טבלת המשפחות).

## משתני סביבה

| משתנה | תיאור |
|---|---|
| `RAILWAY_VOLUME_MOUNT_PATH` | מוגדר אוטומטית על ידי Railway כשמחובר Volume |
| `DATA_DIR` | תיקיית נתונים להרצה מקומית (ברירת מחדל `./data`) |
| `ADMIN_PASSWORD` | סיסמה לדף המנהל. בלי המשתנה הזה דף המנהל חסום |
| `GOAL` | יעד התחלתי (ברירת מחדל 770), ואפשר לשנות אותו בדף המנהל |

## הרצה מקומית

```
node server.js
```
