# 770 דליים של שמחה – דיווח משפחתי

אתר קטן שבו כל משפחה מדווחת: **איזו משפחה**, **איזו קטגוריה** ו**כמה דליים**.
האתר מציג את ההתקדמות לעבר היעד (770 דליים עד ז' חשון), טבלת משפחות ודיווחים אחרונים.

- `server.js` – שרת Node בלי תלויות (רץ ב-Railway). רשימת המשפחות והקטגוריות מוגדרת בראש הקובץ.
- `public/index.html` – האתר עצמו.
- `apps-script/Code.gs` – הקוד ששומר את הדיווחים בגוגל שיטס.

## חיבור לגוגל שיטס (פעם אחת)

1. יוצרים גיליון חדש ב-Google Sheets.
2. בתפריט: **תוספים → Apps Script**. מוחקים את מה שיש ומדביקים את התוכן של `apps-script/Code.gs`. שומרים.
3. **פריסה → פריסה חדשה → סוג: אפליקציית אינטרנט**.
   - הפעלה בתור: **אני**
   - למי יש גישה: **כל אחד**
4. מאשרים הרשאות ומעתיקים את כתובת ה-Web App (מסתיימת ב-`/exec`).
5. ב-Railway, בשירות של האתר → **Variables** → מוסיפים `APPS_SCRIPT_URL` עם הכתובת.

עד שהמשתנה מוגדר, האתר עובד ב"מצב הדגמה" והדיווחים לא נשמרים לאורך זמן.
הדיווחים נשמרים בגיליון "דיווחים", ואפשר לערוך או למחוק שורות ישירות שם.

## משתני סביבה

| משתנה | תיאור |
|---|---|
| `APPS_SCRIPT_URL` | כתובת ה-Web App של Apps Script |
| `APPS_SCRIPT_TOKEN` | רשות: סיסמה, זהה ל-`TOKEN` ב-Code.gs |
| `GOAL` | יעד הדליים (ברירת מחדל 770) |

## הרצה מקומית

```
node server.js
```
